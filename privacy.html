プライバシーポリシー（emperor-ch-analytics）

最終更新: 2026-10-06

このアプリについて

emperor-ch-analytics は、YouTube チャンネル「皇帝ペンギンラボ」の運営者が、自分自身のチャンネルの統計取得・動画のアップロード・コメント投稿を自動化するために使う内部ツールです。一般のユーザー向けに提供するものではありません。

取得する情報

YouTube Data API および YouTube Analytics API を通じて、運営者自身のチャンネルに属する動画の統計情報（再生数・登録者数など）、動画のメタデータ、コメントを取得します。運営者本人以外の Google アカウント情報は取得しません。

情報の利用目的

  • 自分のチャンネルの動画の伸び方を分析するため
  • 自分のチャンネルに動画を投稿し、公開予約やコメント投稿を自動化するため

第三者への提供

取得した情報を第三者に販売・提供することはありません。データは運営者が管理する環境にのみ保存されます。

Google API サービスの利用

このアプリは Google API から取得した情報の利用について、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。また YouTube 利用規約 および Google プライバシーポリシー が適用されます。

アクセス権の取り消し

付与した権限は Google アカウントのセキュリティ設定 からいつでも取り消せます。

お問い合わせ

このポリシーに関する質問は、YouTube チャンネル「皇帝ペンギンラボ」のコメント欄または概要欄の連絡先までお寄せください。
